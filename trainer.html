Recoil Trainer — 100% manual, legal untuk persiapan competitive

Trainer pasif standalone: tidak menggerakkan mouse, tidak membaca game, tidak overlay ke game. Recoil simulasi mendorong titik aim sebesar R(n) = Σ PATTERN[i] tiap tembakan. Kamu lawan manual dengan drag mouse: U(n) = total gerakanmu. Skor = |R(n)+U(n)| — makin dekat ke 0 makin bagus. Pakai sebagai warmup sebelum ranked, bukan dijalankan bersamaan dengan game.

Tips: kuning di atas bg gelap = kontras tertinggi untuk kebanyakan mata. Coba preset lalu geser hue sampai musuh "pop". Setting ini hanya untuk kanvas latihan — tiru di setting game asli (enemy highlight). 
— siap —
1. Klik Mulai (ada hitung 3-2-1 + bunyi tick per shot).
2. Tekan+tahan klik kiri di kanvas, tarik mouse melawan arah titik hijau.
3. Tahan bidik sedekat mungkin ke tengah sampai spray selesai.
best: —
Cara pakai untuk competitive (klik) 1. Latihan di sini 5–10 menit sebagai warmup — jangan dibuka bersamaan dengan match ranked.
2. Target awal: rata-rata miss < 30px dengan guide ON, lalu ulangi guide OFF.
3. Naikkan difficulty: tambah shots, kecilkan interval, turunkan sens.
4. Di game asli, terapkan tarikan yang sama secara manual. Tidak ada software yang jalan saat main → tidak ada pelanggaran ToS.
5. Contoh rutin: 3x AK 20 shots guide ON → 3x guide OFF → 1x blind test.
